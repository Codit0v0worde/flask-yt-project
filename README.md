flask-yt-project/

Структура кода

app/models/ — модели данных (User, Post, Comment), описывающие структуру таблиц и связи между ними (один-ко-многим, многие-ко-многим, рекурсивные связи для комментариев).

app/routes/ — обработчики маршрутов (blueprints), реализующие логику работы с пользователями и темами.

app/templates/ — HTML-шаблоны с использованием наследования и включений (extends/include), что минимизирует дублирование кода.

app/static/ — статические ресурсы: CSS-стили, JavaScript-скрипты, загружаемые пользователями файлы (аватарки, вложения комментариев).

app/forms.py — WTForms-классы, обеспечивающие валидацию и CSRF-защиту.

app/extensions.py — инициализация расширений Flask, что позволяет избежать циклических импортов.

migrations/ — скрипты миграций базы данных (Alembic), позволяющие эволюционно изменять схему БД без потери данных.

nginx/, Dockerfile, docker-compose.yml — конфигурация для развёртывания в контейнерах: веб-сервер Nginx, uWSGI-сервер для Flask, отдельный контейнер с PostgreSQL.

Используемые технологии

Backend: Python 3.11.14, Flask 3.0, Flask-SQLAlchemy (ORM), Flask-Migrate (миграции БД), Flask-Login (аутентификация), Flask-Bcrypt (хеширование паролей), Flask-WTF (формы и валидация), Flask-Assets (сборка статики).

База данных: PostgreSQL 15.

Фронтенд: HTML5, CSS3, JavaScript, Bootstrap , Jinja2 (шаблонизатор), Font Awesome  (иконки).

Инфраструктура: Docker, Docker Compose (контейнеризация), Nginx (веб-сервер), uWSGI (сервер приложений), Git (система контроля версий).


Возможности:

Общие:

-Регистрация и аутентификация (вход/выход).

-Просмотр главной страницы со списком учебных тем, включая фильтрацию по преподавателю и  поиск по названию.

-Просмотр  страницы темы .

-Возможность оставлять комментарии к темам, прикреплять файлы (изображения, документы).

-Личный кабинет: просмотр и редактирование профиля (имя, аватар), смена пароля.
