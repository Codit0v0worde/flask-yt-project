> Веб-приложение для создания и обсуждения учебных тем с ролевой моделью, курсами, комментариями и файлами.  

Это  веб-приложение на Flask, которое позволяет организовать взаимодействие между преподавателями и студентами. Преподаватели создают курсы, внутри которых могут размещать лекции, практические задания (с файлами) и ссылки на Zoom. Студенты могут просматривать материалы, комментировать их и отвечать на задания. Исходный код доступен на GitHub.

##  Функциональные возможности

### Общие возможности (для всех авторизованных)
- Регистрация и аутентификация (вход/выход).
- Просмотр главной страницы со списком учебных тем, фильтрация по преподавателю и полнотекстовый поиск по названию.
- Просмотр детальной страницы темы с древовидными комментариями, возможность прикреплять файлы.
- Личный кабинет: просмотр и редактирование профиля (имя, аватар), смена пароля.
- Просмотр курсов, разделов и активностей (лекции, задания, Zoom).

### Ролевая модель
- **`user` (студент)** – может просматривать темы, курсы, оставлять комментарии, отправлять ответы на задания.
- **`teacher` (преподаватель)** – создаёт курсы, разделы, активности (лекции, задания, Zoom); оценивает ответы студентов.
- **`starosta` (староста)** – может управлять ролями пользователей (кроме суперпользователя и своей роли).
- **`enginiger` (суперпользователь)** – создаётся автоматически при первой регистрации. Имеет абсолютные права: может всё, включая редактирование/удаление любых записей и назначение ролей.

### Управление курсами
- Создание, редактирование, удаление курсов (только преподаватели и `enginiger`).
- Внутри курса можно создавать разделы, а в них – активности трёх типов:
  - **Лекция** – текстовый материал с возможностью прикрепить файл.
  - **Задание** – практическая работа с датами открытия/закрытия, возможностью отправки ответов и файлов, оцениванием преподавателем.
  - **Ссылка на Zoom** – просто ссылка на онлайн-занятие.

### Комментарии и обсуждения
- Комментарии к темам с поддержкой вложенности (ответы).
- Возможность прикреплять файлы к комментариям.
- Преподаватели могут выставлять числовые оценки (1–5) в комментариях.

### Прочее
- Полнотекстовый поиск по темам.
- Фильтрация тем по преподавателю.
- Личный кабинет с отображением активности (созданные темы, комментарии).
- Управление пользователями для старост и суперпользователя.
- Кастомная страница 404 с ироничным сообщением.
